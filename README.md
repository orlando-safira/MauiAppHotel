# .netmauihotel 🏨

Aplicativo mobile desenvolvido em **.NET MAUI** no **Microsoft Visual Studio** com o objetivo de realizar o cálculo de diárias e gerenciar reservas de hotéis.

---

## 🚀 Funcionalidades

* **Seleção de Hóspedes:** Controles intuitivos (`Steppers`) para definir a quantidade de adultos e crianças.
* **Escolha de Acomodação:** `Picker` interativo para selecionar o tipo de suíte desejada.
* **Período de Estadia:** Seleção de datas de *Check-in* e *Check-out* utilizando `DatePickers`.
* **Tela Sobre:** Página dedicada com informações do aplicativo, nome do desenvolvedor e ano de desenvolvimento.
* **Layout Personalizado:** Interface moderna utilizando recursos de estilização do .NET MAUI (`Grids`, `VerticalStackLayout`, `Frames`).

---

## 🛠️ Tecnologias Utilizadas

* **.NET MAUI** (Multi-platform App UI)
* **C#** (Lógica de Programação e Code-Behind)
* **XAML** (Construção de Interfaces)
* **Microsoft Visual Studio** (Ambiente de Desenvolvimento)
